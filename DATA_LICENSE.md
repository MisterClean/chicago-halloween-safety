# Data and map attribution

The MIT license covers this project's code. It does not relicense city records or map data.

The fetch scripts retrieve records from the [City of Chicago Data Portal](https://data.cityofchicago.org/). Review the terms linked from the portal's [official FAQ](https://data.cityofchicago.org/stories/s/Chicago-Data-Portal-FAQ/iy9c-7e89) and each dataset's current metadata before redistributing records. This project is independent of the City of Chicago.

Protomaps basemaps include OpenStreetMap and other sources. Preserve the attribution supplied by the map style and review [Protomaps basemap attribution](https://github.com/protomaps/basemaps/blob/main/README.md#attribution) and [OpenStreetMap's copyright and license page](https://www.openstreetmap.org/copyright) when hosting the page yourself.

Raw downloads and generated data files are not included in this repository. A local build exports aggregated crash information and selected permit-location fields, not raw People or permit contact records.
